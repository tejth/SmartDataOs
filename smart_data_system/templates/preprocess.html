Missing Value Handler

Fill nulls with mean, median, mode, or zero — or drop rows entirely. Text columns auto-filled with mode.

📍

Outlier Removal

Removes statistical outliers using the IQR method — values beyond Q25 − 1.5×IQR or Q75 + 1.5×IQR are dropped from every numeric column.

📏

Normalisation & Standardisation

Min-Max scaling compresses values to 0–1. Z-Score standardisation shifts distribution to mean=0, std=1. Apply to all or specific columns.

✂️

Column Dropper

Drop any unwanted columns by name — useful for removing ID columns, redundant fields, or high-cardinality text columns before modelling.

🔁

Duplicate Remover

Detects and removes exact duplicate rows using df.duplicated(). Keeps the first occurrence and drops all subsequent copies.
